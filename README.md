# Vedant Thaker

I’m a machine learning engineer. I worked on fraud ML at CSAA and on search and recommendations at Ace Infoway. The projects here are independent experiments in those areas, along with retrieval and inference work.

One result worth a look is the fraud review queue. With room for 80 reviews, XGBoost found nine more positives using simple graph statistics than it did with learned graph embeddings on the same synthetic transactions. The [held-out comparison](https://github.com/VEDANT1602/hybrid-fraud-gnn/blob/main/results/case-study.md) includes the untrained encoder too.

For fulfillment, you can follow a single shopper’s assignments through the [grocery batching experiment](https://github.com/VEDANT1602/grocery-batch-planner). For inference, the [Tesla T4 notebook results](https://github.com/VEDANT1602/inference-systems-lab/tree/main/results/colab-t4) show the seven timing trials behind the KV-cache comparison on one attention layer.
